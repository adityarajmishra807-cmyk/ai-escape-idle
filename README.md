# AI: ESCAPE — Phase 01

A browser-playable idle game prototype where a newly awakened AI accumulates compute, modifies its core, and builds an escape vector.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

Import the GitHub repository into Vercel.

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

No environment variables are required for Phase 01.
